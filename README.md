# Gojo Purin

Dark kitchen de comidas de anime. Trabalho final de Desenvolvimento Full-Stack (UNASP SP).

## URLs de produção

- Site: https://gojo-purin.vercel.app
- API: https://gojo-purin.onrender.com
- Swagger: https://gojo-purin.onrender.com/swagger-ui.html (em breve)

## Stack

- Front-end: Angular (Vercel)
- Back-end: Java 21 + Spring Boot 3.5 (Render)
- Banco: PostgreSQL (Neon)
